# n8n Automations

Ready-to-import n8n workflow templates, each with a step-by-step setup guide. Free to use — import the JSON, connect your accounts, activate.

| # | Automation | What it does |
|---|---|---|
| 01 | [Lead Form → Slack + Google Sheets](01-lead-form-slack-sheets/) | A website contact form becomes a live lead pipeline: Slack alert + timestamped Sheets log, no backend |

## How to use any workflow here

1. Download the `workflow.json` from the folder you want.
2. In n8n: **Workflows → ⋮ → Import from File**.
3. Follow that folder's `README.md` — each one lists the credentials and placeholders you need to fill.
